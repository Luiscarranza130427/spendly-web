# Spendly — Paleta visual de referencia

Paleta sugerida para que Antigravity mantenga consistencia con los assets:

- Verde principal: `#08B889`
- Verde esmeralda: `#0C8F72`
- Verde oscuro: `#075D50`
- Menta clara: `#DDF7EC`
- Fondo suave: `#F6FAF8`
- Texto principal: `#102A2A`
- Texto secundario: `#5F7270`
- Blanco: `#FFFFFF`

Usar los valores como referencia visual, no como obligación si el código
actual de Spendly ya tiene tokens oficiales distintos.

# Spendly Media Pack

Pack preparado para construir la web pública de Spendly con Antigravity.

## Contiene

- logos de referencia;
- Hero;
- mockups;
- ilustraciones de funciones;
- seguridad;
- multidispositivo;
- metas;
- pricing reference;
- imagen de sidebar;
- backgrounds;
- assets sociales;
- tableros de referencia;
- copy completo de la landing;
- manifiesto de assets;
- paleta visual.

## Uso recomendado

Entregar esta carpeta/ZIP a Antigravity junto con el repositorio de Spendly.
Pedirle que use los assets como referencia visual y que, cuando existan
screenshots reales del producto, prefiera los screenshots reales sobre los
mockups conceptuales.
